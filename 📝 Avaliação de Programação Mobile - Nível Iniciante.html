🔀 PARTE 1 · Questões de Verdadeiro (V) ou Falso (F) com Sequência
Questão 1 — HTML, CSS e JavaScript
1,0 ponto
Analise as afirmativas a seguir sobre as responsabilidades das tecnologias no desenvolvimento de aplicações web/mobile (HTML, CSS e JavaScript):

(I) O HTML é responsável por definir a estrutura e os elementos que existem na tela, como textos, títulos, botões e formulários.

(II) O CSS cuida da aparência visual da aplicação, definindo estilos como cores, fontes, margens, bordas e dimensões.

(III) O JavaScript substitui completamente o HTML e o CSS, sendo utilizado unicamente para desenhar os layouts estáticos da interface.

Assinale a opção que apresenta a sequência correta de V ou F:
✅ CORRETA Resposta correta: A
📖 Justificativa: I e II são verdadeiras. III é falsa pois o JavaScript cuida do comportamento e interatividade, não do layout estático.
Questão 2 — Android e Dispositivos Móveis
1,0 ponto
Analise as afirmativas a seguir sobre a origem, arquitetura e recursos do ecossistema Android e dispositivos móveis:

(I) A arquitetura do sistema operacional Android possui o Kernel Linux em sua camada base.

(II) O runtime ART (Android Runtime) foi introduzido no Android como uma evolução da antiga máquina virtual Dalvik.

(III) Dispositivos móveis não possuem capacidade de integrar sensores físicos como GPS, câmera ou acelerômetro às suas aplicações.

Assinale a opção que apresenta a sequência correta de V ou F:
✅ CORRETA Resposta correta: B
📖 Justificativa: I e II são verdadeiras. III é falsa pois aplicações móveis utilizam frequentemente sensores como GPS e câmera.

Questão 3 — Manipulação de Elementos
1,0 ponto
No desenvolvimento de interfaces dinâmicas, qual estrutura/mecanismo é responsável por permitir que o JavaScript localize, leia, modifique e altere o conteúdo ou estilo dos elementos da tela em tempo real?

📖 Justificativa: O Document Object Model permite ao JS localizar e manipular elementos da tela em tempo real.
Questão 4 — Formulários em JavaScript

Ao criar formulários interativos em JavaScript, qual propriedade booleana (que retorna true ou false) é utilizada para verificar se uma caixa de seleção (<input type="checkbox">) está marcada pelo usuário?
✅ CORRETA Resposta correta: C
📖 Justificativa: A propriedade .checked é booleana e indica se o checkbox está marcado (true/false).

Durante a fase de planejamento e estruturação de um projeto mobile (antes da escrita do código), qual ferramenta/esboço visual é utilizado para rascunhar o layout e a hierarquia da interface?

Questão 6 — Low-Code vs Tradicional
1,0 ponto
Plataformas visuais e low-code (como App Inventor, Kodular e Thunkable) permitem criar aplicativos arrastando componentes. No paralelo entre o desenvolvimento visual e o desenvolvimento tradicional, a qual elemento do desenvolvimento tradicional corresponde um bloco de evento (ex: evento de clique)?

✍️ PARTE 3 · Questões Abertas
Questão 7 — Papéis de HTML e CSS
1,0 ponto
Explique sucintamente a diferença de papéis entre o HTML e o CSS na construção de uma interface web/mobile.
Máximo recomendado: 3 linhas
💡 Sugestão de Resposta
O HTML é responsável pela estrutura da interface, definindo os elementos presentes na tela (como textos e botões). O CSS cuida da aparência visual, estilizando aspectos como cores, fontes, margens e alinhamentos.
📝 Sua resposta: HTML estrutura e organiza o conteúdo da página. CSS define o visual, como cores, fontes, tamanhos e posicionamento. Juntos, permitem criar interfaces organizadas, bonitas e responsivas.
Questão 8 — DOM (Document Object Model)
1,0 ponto
O que é o DOM (Document Object Model) e qual é a sua importância para a interatividade de um aplicativo?
Máximo recomendado: 3 linhas
💡 Sugestão de Resposta
O DOM é a representação da estrutura da tela na memória que permite ao JavaScript acessar, ler e alterar elementos dinamicamente. Ele é essencial para redefinir textos, cores e conteúdos em resposta às ações do usuário.
📝 Sua resposta: O DOM é a representação da estrutura HTML de uma página em forma de árvore de elementos. Ele permite que o JavaScript acesse e altere esses elementos. Assim, possibilita criar interações e tornar o aplicativo mais dinâmico.
Questão 9 — Wireframe
1,0 ponto
Quais são as vantagens de criar um wireframe antes de iniciar o desenvolvimento do código de um aplicativo?
Máximo recomendado: 3 linhas
💡 Sugestão de Resposta
O wireframe permite planejar o layout, a hierarquia visual e a experiência do usuário (UI/UX) de forma rápida antes de programar. Isso evita retrabalho de código, reduz custos e ajuda a validar a ideia da interface previamente.
📝 Sua resposta: O wireframe ajuda a planejar a estrutura e a organização das telas antes da programação. Facilita identificar erros e melhorar a experiência do usuário. Também economiza tempo e reduz alterações durante o desenvolvimento.
Questão 10 — Sensores em Dispositivos Móveis
1,0 ponto
De que maneira os sensores de um dispositivo móvel (como GPS ou câmera) podem agregar valor a um aplicativo? Dê um exemplo prático.
Máximo recomendado: 3 linhas
💡 Sugestão de Resposta
Os sensores conectam a aplicação ao ambiente físico do usuário, tornando-a mais inteligente e funcional. Por exemplo, o GPS pode ser usado para calcular rotas de entrega e a câmera para leitura de códigos de barras ou QR Codes.
📝 Sua resposta: Os sensores permitem que o aplicativo utilize recursos do dispositivo para oferecer funções mais úteis e interativas. Por exemplo, o GPS pode ser usado em aplicativos de mapas para indicar a localização do usuário. A câmera também pode ser usada para tirar fotos ou ler QR Codes.
